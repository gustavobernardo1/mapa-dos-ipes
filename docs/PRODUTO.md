# Produto

Marca inicial: **Mapa dos Ipês**, Goiânia — GO. Proposta: “Descubra, fotografe e ajude a mapear a florada dos ipês de Goiânia.” Campanha inicial `IPES_GOIANIA_2026`.

Mensagem: **🌼 A florada está acabando. Vamos registrá-la.** Ainda dá tempo de ajudar a registrar os ipês que estão colorindo Goiânia em 2026. Fotos antigas também contribuem para o histórico.

Árvore é permanente; observação é temporal; fotografia pertence a uma observação. Uma nova observação não deve criar outra árvore quando o colaborador ou moderador reconhece o mesmo exemplar. A referência visual original é `Mapa dos Ipês_ Goiânia em Flor.png` na raiz. A interface preserva mapa predominante, busca, chips, cores, clusters e painel inferior sem reproduzir seus números fictícios.

Rotas: `/`, `/explorar`, `/registrar`, `/galeria`, `/guia`, `/arvore/[id]`, `/ciencia`, `/privacidade`, `/admin`. Navegação móvel: Mapa | Explorar | Registrar | Galeria | Guia.

Cor e fenologia são observações; identificação do usuário é uma hipótese. A floração recente se refere aos **últimos 7 dias da data observada**, não à data de upload. Sem dados, estatísticas são zero. Se o serviço falha, a interface mostra erro em vez de apresentar zero como resultado do banco.

Todo envio começa pendente. Apenas observações e árvores aprovadas são públicas. Revisão comunitária para galeria não equivale a ground truth científico. Confiança inicial D; o moderador avalia A (atual verificado), B (histórico verificado), C (parcial) e D (declarado). Não há percentuais inventados.

Guia botânico e privacidade são rascunhos marcados para revisão antes do lançamento. Não há IA de identificação, previsão de florada, detecção satelital, rotas otimizadas ou promessa de identificação infalível. O notebook é uma preparação para investigação futura.

Arquitetura genérica: espécies, árvores, observações, fotos e campanhas permitem futuras sibipirunas, jacarandás, flamboyants, chuva-de-ouro, quaresmeiras e outras campanhas. A interface pública inicial permanece focada em ipês. A gestão de novas campanhas na interface não faz parte deste MVP.
